# What an agentic AI SOC is

**Awareness**

An agentic AI SOC is a security operations model where AI agents perform the triage and investigation work historically done by Tier 1 and 2 analysts, at machine speed, with human analysts authorizing the decisions.
This section defines the model, explains how the agents are built and constrained, and covers the two questions that separate a real platform from an LLM wrapper: can it explain its decisions, and does a human stay in control. It also maps where the category is heading in 2026.
